安装
1. 先在旧版导出完整加密备份并记住密码。
2. 保留原应用，使用新 APK 覆盖安装；本包与此前发布包使用同一发布者 Debug 签名。自行构建的包可能签名不同。
3. 文件名须以 .apk 结尾。如下载后是 .apk.1，先去掉最后的 .1，再用系统文件管理器打开。
4. 不要卸载或清除数据来解决安装问题，以免丢失本机账本。

配置 DeepSeek
1. 用本人账户在 https://platform.deepseek.com/ 创建 API Key，并确认余额；费用由本人 DeepSeek 账户承担。
2. 打开轻记底部“助手”→“DeepSeek 设置”，在密码框输入 Key，勾选“启用 DeepSeek”并保存。
3. 默认模型 deepseek-flash，也可选择 deepseek-v4-pro。保存设置不代表已验证 Key 或实际 API 可用性。
4. 输入“昨天午餐28.50元”等完整需求，点击“发送给 DeepSeek”。草稿需“核对并记账”后在编辑器保存，助手不会直接写账本。
5. 可查询今天、本月、上月收支，解释待确认原因，或检查识别连接。退款须在识别中心关联原消费，转账与还款不算新增消费。

数据与网络
Key 使用 AndroidKeyStore 保护的密钥加密保存，不回显，不进入财务备份。请仅在手机应用设置里输入 Key，不要发到聊天、反馈、截图或公开仓库。
默认只发本次输入、固定规则、当地日期和工具定义；不自动附逐笔账单、通知、页面原文或图片。
只有本次单独勾选后，才可回传收支、固定分类及待确认数量和原因计数；每次发送后重置授权。
每次请求独立，不带历史聊天。离开页面取消请求并清空页面会话；已到服务端的请求可能产生费用，取消不能撤回。
2.1 新增网络权限，DeepSeek 只由主动发送触发。本地 OCR 仍在设备上处理，ML Kit 可能联网发送 SDK 使用、性能和设备诊断信息；关闭 DeepSeek 不会撤销网络权限或关闭 SDK 通信。
