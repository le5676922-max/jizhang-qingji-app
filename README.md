# 记账轻记app · Android 本地自动记账

**`main` 是 V2.0 开发中的源码快照（`versionName 2.0`、`versionCode 3`），不是已发布的 V2 成品。** 已交付的可安装版本是 **1.1 测试版（`versionCode 2`）**，请到 [GitHub Releases](https://github.com/le5676922-max/jizhang-qingji-app/releases) 下载。首次公开的 `initial-public-snapshot` 标签保存 V2 开发源码，随附的 APK 是较早已交付的 1.1 测试包，并非从该标签构建的 V2 安装包。V2 的新识别中心、多来源匹配及完整备份恢复尚未完成接入与整体验证，进度见 [开发状态](docs/development-status.md)。

应用使用 Kotlin、Jetpack Compose、Material 3 和本机 SQLite，实现通知、交易页面文字与本地 OCR 识别。Android 7.0（API 24）以上可运行，自动截图需要 Android 11（API 30）以上。三星 S23 Ultra 满足这些 API 要求，但真实手机及当前微信、支付宝页面的覆盖尚未验证。

## 1.1 测试版已有能力

- **屏幕记账**：主动开启无障碍后，读取微信、支付宝已打开的单笔交易结果或详情页；严格检查完成状态、金额及资金方向。
- **本地 OCR**：在符合条件且系统允许截图的结果页识别不可读的文字，也支持主动导入支付截图。OCR 结果先进入待确认。
- **通知记账**：识别开启后新收到的付款、到账、退款系统通知；通知与屏幕疑似重复时提示核对。
- **本地账本**：手动补录、编辑删除、预算、月度收支、分类统计、搜索与 CSV 导出。金额以整数分保存，无需账号或云识别接口。

微信转账或发红包可能只产生应用内消息，没有包含金额的系统通知。这时需要打开可读取的单笔交易结果或详情页，或主动导入允许截图的凭据。

## 安装与三星权限设置

从 [GitHub Releases](https://github.com/le5676922-max/jizhang-qingji-app/releases) 下载 1.1 测试版 APK。1.1 与原 1.0 使用同一包名、同一签名，可覆盖升级保留本机账本。文件名必须以 `.apk` 结尾；若下载后变成 `.apk.1`，先删除末尾 `.1`，再通过系统文件管理器打开，并按系统提示允许该来源安装。

1. 打开轻记的「自动记账」→「屏幕记账」，开启「识别交易结果页」，阅读并同意用途说明。
2. 若三星阻止启用无障碍，进入手机 **设置 → 应用 → 轻记 → 右上角 ⋮ → 允许受限设置**，按系统要求确认身份。该入口是否显示取决于系统版本与安装来源。
3. 再进入 **设置 → 辅助功能／无障碍 → 已安装的应用 → 轻记 · 屏幕记账**，启用服务。
4. 返回轻记，检查服务状态确实显示 **「已连接」**。「已授权，等待连接」只表示已授予权限，服务还没有连接，不能据此判断采集已开始。
5. 保留微信、支付宝来源开关。转账或发红包后，打开成功页、转账详情或红包详情并停留片刻；聊天列表、输入金额、密码页和普通账单列表不会采集。
6. 按需开启「结果页截图识别」。自动截图有 8 秒限频，是否允许截图由系统和支付应用决定；识别结果在「查看待确认账单」中核对后保存。
7. 无法自动读取时，用「导入支付截图识别」选择来源和交易结果图。导入不要求自动屏幕开关开启；不能截图的安全页面请手动记账。

「通知记账」可以单独开启：允许通知访问、开启「自动记录收支」。它只处理开启后收到的新通知，不回扫历史。系统显示已授权但服务未连接时，应先检查连接状态，再测试新的交易结果页或通知。

## 为什么交易会待确认或没有记录

**待确认不会直接计入统计。** 屏幕识别中的 OCR、缺少稳定身份（例如既无交易单号也无秒级交易时间）、只有分钟时间、历史凭据、疑似重复、方向不明以及页面内容变化，都需要人工核对金额、方向、日期与重复情况。不同交易单号的同金额交易应保持独立；不能只凭金额相同认定重复。

1.1 主要区分资金转出和转入。转给朋友、钱包之间转移、还款或退款，不一定等于消费支出或新增收入；使用时应核对真实用途与统计口径。V2 正在增加业务类型与退款关联，相关完整流程尚未交付，不能把这份开发快照当作已经解决全部转账语义问题的版本。

仅有「待领取」但没有红包已经发出、扣款的证据，不会判为成功支出；转账待收款也需要明确转出成功的依据。未付款、失败、输入金额、密码、普通聊天、多笔交易列表及未知布局不会作为自动入账证据。

付款页面不是稳定开放接口。应用可能隐藏敏感节点，`FLAG_SECURE` 窗口不能截图，本项目不绕过这些保护。没有通知，也没有打开可读取的单笔结果页时，无法得到交易金额；不能承诺完整银行流水覆盖。

## 本地数据与权限

中文 ML Kit 模型捆绑在应用内，设备端处理，主 App 不声明 `INTERNET` 权限。无障碍服务只读取授权来源，不点击、不输入、不支付；可在轻记或系统设置中关闭。

自动截图仅在内存使用，账本保存提取字段与哈希身份，不保存完整通知、屏幕原文、银行卡号、验证码或图片。本地账本会随卸载删除，系统备份关闭。1.1 建议定期导出 CSV，但不提供 CSV 恢复；完整加密备份恢复仍是 V2 开发项。预算是全局月度额度。
