更新日期：2026-10-15（Asia/Shanghai）。本页描述 2.1 测试版的配置与数据边界；[下载 APK 及匹配源码](https://github.com/le5676922-max/jizhang-qingji-app/releases/tag/v2.1-test)，[本轮验证与校验值](verification-deepseek-v2.1.md)。已发布的 2.0／2.0.1 APK 不包含此助手；历史版本与下载入口见 [README](../README.md)。

## 在手机配置

1. 使用本人 DeepSeek 开放平台账户创建 API Key，并查看账户余额及计费规则。API 费用由该账户承担；应用不提供公共 Key，也不代充值。[DeepSeek 开放平台](https://platform.deepseek.com/)与[官方模型及价格](https://api-docs.deepseek.com/quick_start/pricing/)为准，本文不固定价格。
2. 在轻记打开底部「助手 → DeepSeek 设置」，将 Key 粘贴到密码输入框。**仅在手机应用的设置框输入，不发到聊天、问题反馈、截图或公开仓库。**
3. 选择模型并勾选「启用 DeepSeek」，点击「保存设置」。当前支持 `deepseek-flash`（默认）与 `deepseek-v4-pro`；模型标识按 2026-10-15 的官方文档核对。保存只是本机安全存储，不代表密钥、余额或真实 API 请求已验证。
4. 返回助手，输入完整需求，再点击「发送给 DeepSeek」。常用短语只填入输入框，不自动发送。默认不附本地账本汇总。

Key 已保存时只显示状态，不回显原文；新 Key 留空会保留已有 Key。点击「清除 API Key」会删除本机保存的 Key 并关闭 DeepSeek；如果要撤销该 Key 在其他地方的使用，还需到 DeepSeek 平台操作。密钥不可用、余额不足、限流或网络失败时会给出固定安全提示，不显示认证头、HTTP 错误响应原文或密钥。

未配置或未启用时，按钮显示「本地查询」，可使用「本月收支」「今天收支」「上月收支」「为什么还要确认」「检查连接」等固定短语；这条本地查询路径不调用 DeepSeek。理解其他自然语言和生成记账草稿需要先配置模型。

## 四个本地工具

模型可以提出工具调用，具体数据检查和计算由手机执行；模型本身不获得直接操作账本的权限。[DeepSeek 官方 Tool Calls 说明](https://api-docs.deepseek.com/guides/tool_calls/)也区分了模型提出调用与客户端执行工具。

| 工具 | 提供的结果 | 需要用户完成的操作 |
| --- | --- | --- |
| `prepare_entry` | 校验金额、资金方向、用途、分类和日期，生成一笔尚未保存的人工草稿 | 点击「核对并记账」，在原编辑器核对并保存；助手不自动入账 |
| `query_summary` | 本地计算今天、本月或上月的收入、消费、退款、净支出、结余与固定分类汇总 | 无需写入账本；数字以本地核算为准 |
| `explain_pending` | 展示待确认数量与固定原因类型计数 | 到识别中心核对交易；助手不能代为确认、关联或忽略 |
| `check_connection` | 解释通知／屏幕服务的授权、开关与实际连接状态 | 由用户到系统设置或连接排查页操作；助手不能修改授权或强制重连 |

例如发送「昨天午餐 28.50 元」，可得到待核对的支出草稿；如缺金额或用途，应补充完整信息，而非直接保存。转账、还款与消费使用不同经济类型，不能把所有资金转出都当作消费。退款仍需到识别中心关联原消费，助手不生成自动关联退款。

模型文字只作为建议。查询金额由本地统计工具生成，模型没有工具核算依据的数字不应视为账本事实。助手没有删除、批量导出、直接确认账单、修改预算／权限、执行代码、访问任意网址或在微信内点击付款的工具。

## 每次发送的数据

| 情况 | 本项目发给 DeepSeek 的内容 | 保留在本地的内容 |
| --- | --- | --- |
| 默认发送 | 本次主动输入、固定助手规则、当前本地日期与工具定义；API Key 作为 HTTPS 认证凭据 | 历史聊天、本地正式账本与全部明细、通知／页面原文、图片与 OCR 原文、连接状态 |
| 本次单独勾选共享汇总 | 在默认内容之外，可将本次查询产生的收支汇总金额、固定分类、记录数量、期间，或待确认数量及固定原因计数作为工具结果回传 | 逐笔金额／时间、商家、备注、单号／哈希身份、截图与通知正文仍不回传；连接报告始终本地展示 |
| 未启用时的本地查询 | 不调用 DeepSeek | 本地工具结果 |

**输入框中主动写入的金额、商家或其他个人内容本身会被发送。**「不附账本」不意味着会删除你自己输入的信息。不要在需求中填写 API Key、支付密码或其他不必要的敏感内容。

共享汇总选项默认关闭，每次发送后重置，不能一次勾选后永久授权。允许共享并不保证每条问题都会上传汇总：只有实际调用允许的汇总工具时才可能回传，不序列化全部账本供模型阅读。未知工具与参数会被拒绝，工具输出不能授权新增权限。

每次用户发送都是独立请求，不携带页面中此前的聊天。一次请求内部允许有限的模型与工具往返，最多三轮模型调用、四个工具调用；没有应用层自动重试。若希望修改上一条需求，请重新写出完整金额、用途与日期，不依靠「就按刚才那个」等历史上下文。页面仅在内存保留最近 12 回，切页或 Activity 重建后清空；不写入 SQLite、CSV 或完整财务备份。

请求期间可取消，不能重复提交或修改 DeepSeek 设置。离开页面会取消任务，迟到回复不再显示，也不会保存账本。已发到服务端的请求可能已产生费用，取消不能撤回服务端已经接收的内容。草稿按钮只打开现有编辑器；在账本恢复阻断时不会打开写入入口。

## 网络权限、密钥与第三方 SDK

2.1 为模型接入声明 `INTERNET`，它是安装时授予的普通权限；不等同于通知访问或无障碍授权。应用禁止明文流量；本项目的 DeepSeek 客户端只请求固定的 `https://api.deepseek.com/chat/completions`，使用系统 HTTPS 校验、不跟随重定向，不提供自定义代理／第三方模型地址或忽略证书的开关。密钥、认证头、输入和响应不写入应用日志。

API Key 使用 AndroidKeyStore 中不可导出的 AES 密钥及 AES-256-GCM 加密，密文保存在独立的应用私有偏好中；安全存储失败不会改存明文。保存状态不保证加密材料在系统重置或异常迁移后仍可用，失效时需重新配置。财务备份不包含 Key、DeepSeek 配置或会话；在原手机恢复财务备份也不会从备份导入 DeepSeek 授权。系统备份与迁移规则排除私有配置。

通知、页面节点与截图识别不会自动触发本项目的 DeepSeek 客户端。OCR 仍使用捆绑 ML Kit 中文模型在设备端处理，未改为上传图片的云 OCR。**网络权限存在后，不能承诺整个 App 无后台网络**：Google 说明 ML Kit 可能联系服务器并发送性能／使用指标；SDK 数据披露还包括设备／应用信息、安装范围标识及 API 配置等诊断项。Google 说明输入图片和识别输出在设备端处理，不发送至其服务器。[ML Kit 隐私说明](https://developers.google.com/ml-kit/terms#privacy)、[Android SDK 数据披露](https://developers.google.com/ml-kit/android-data-disclosure)。关闭 DeepSeek 只停用本项目的模型调用，不会从安装包撤销网络权限，也不是 ML Kit 遥测关闭开关。

DeepSeek 收到内容后的服务端处理适用其平台规则，应用不承诺对方不留存、即时删除或零费用。这里的本地密钥加密和选择性上传不能替代服务商的处理条款。[完整采集与备份边界](privacy.md)说明了本地识别和财务数据的其他处理方式。

## 与自动记账、机型兼容的关系

接入 DeepSeek 不会让未连接的无障碍服务自动连接，也不会补出未采集到的微信转账、红包或扫码付款。显示「已授权，等待系统连接」时，应先查看 [连接排查](connection-troubleshooting.md)，无需再次付款。助手只能解释状态，不能越过系统绑定、支付应用隐藏节点或安全截图限制。

最低 Android 7.0、不同系统的截图能力、厂商后台策略、16 KB 和真实支付页面覆盖仍受 [Android 兼容说明](android-compatibility.md)限制。DeepSeek 需要可访问官方 API 的网络、有效账户和系统安全存储，不能以模型接入推断所有安卓型号均可用。

本轮 229 项 JVM 测试和 API 24、API 37 各 193 项完整设备测试通过，使用合成数据与模拟模型响应；真实付费 API 调用、各品牌真机及当前微信／支付宝页面尚未验收，不能用这些数量替代真实场景覆盖率。[2.1 验证记录](verification-deepseek-v2.1.md)保留了失败及复跑过程。
